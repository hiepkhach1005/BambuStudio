# Dự án cảm ứng Windows + iPadOS

Đọc theo thứ tự: STATUS → DECISIONS → file của phần đang làm.

| File | Dùng để | Khi nào cập nhật |
|---|---|---|
| STATUS.md | Đang làm gì, bị chặn gì, bước kế | Đầu/cuối mỗi phiên |
| TASKS.md | Danh sách việc, chủ file, trạng thái | Khi việc đổi trạng thái |
| HISTORY.md | Nhật ký việc đã làm (chỉ thêm) | Xong mỗi việc |
| DECISIONS.md | Quyết định và lý do | Khi chốt/đổi quyết định |
| LESSONS.md | Lỗi đã gặp, cách tránh | Khi học được điều mới |
| TESTING.md | Kết quả trên máy thật | Sau mỗi lần thử |
| PARITY.md / PRIOR_ART.md / ARCHITECTURE.md | Tính năng gốc / repo đi trước / thiết kế iPad | Khi có thay đổi |
